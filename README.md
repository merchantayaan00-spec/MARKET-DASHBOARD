# Morning Market Dashboard

A personal, static market dashboard hosted on GitHub Pages and refreshed by GitHub Actions. Nothing sensitive lives in this repo: no keys, no personal data.

**Live page:** https://merchantayaan00-spec.github.io/MARKET-DASHBOARD/ (after you finish the setup below)

## What is where

| File | What it does |
|---|---|
| `index.html`, `assets/` | The page (HTML, CSS, JS). No build step. |
| `data/deals.json` | **All deal content** (terms, updates, practice questions). |
| `data/market.json`, `data/news.json` | Generated by the workflow. Do not edit by hand. |
| `scripts/update_data.py` | Fetches quotes, FRED data, finance-only WSJ headlines, deal news. |
| `.github/workflows/update-data.yml` | Runs the script weekdays at 8:30 AM and 4:30 PM Eastern. |
| `DEALS_UPDATE.md` | Instructions for the weekly deal research update. |

## One-time setup

### 1. Merge the pull request
The work is on a branch and in a draft pull request. On GitHub, open the PR, click **Ready for review**, then **Merge pull request**. GitHub Actions schedules and GitHub Pages both run from `main`, so this step is required.

### 2. Make the repo public
GitHub Pages on a free account needs a public repo.
1. Repo page, **Settings** (top tab).
2. Scroll to the bottom, **Danger Zone**, **Change repository visibility**, **Make public**, and confirm.

Nothing sensitive is in the repo. The FRED key goes in a GitHub secret (next steps), never in code.

### 3. Turn on GitHub Pages
1. **Settings**, then **Pages** (left sidebar).
2. Under **Build and deployment**, **Source**: choose **Deploy from a branch**.
3. **Branch**: `main`, folder `/ (root)`, then **Save**.
4. Wait 1-2 minutes. The page address appears at the top of that screen: `https://merchantayaan00-spec.github.io/MARKET-DASHBOARD/`. Pin that tab in Chrome.

### 4. Get a free FRED API key and store it as a secret
Needed for rates and the consumer macro data (Treasury yields, fed funds, mortgage rate, sentiment, retail sales, unemployment, savings rate, gas price, delinquencies).
1. Create a free account at https://fredaccount.stlouisfed.org/ and sign in.
2. Go to https://fredaccount.stlouisfed.org/apikeys and click **Request API Key**. Fill in a short description (e.g. "personal dashboard") and accept the terms. Copy the 32-character key.
3. In your GitHub repo: **Settings**, **Secrets and variables**, **Actions**, **New repository secret**.
4. Name: `FRED_API_KEY` (exactly). Secret: paste the key. **Add secret**.

No other source needs a key: quotes come from Yahoo Finance, headlines from WSJ's public RSS feed, deal news from Google News RSS.

### 5. Run the first refresh
**Actions** tab, **Refresh market data**, **Run workflow**, **Run workflow**. It takes about a minute and commits updated files in `data/`. Reload your dashboard. After that it runs by itself on weekdays at 8:30 AM and 4:30 PM Eastern.

If a run fails: open the run, then the step that failed, and read the log. The page keeps showing the last good values (with a small "stale" label) until the next success.

## Day to day

### Update the deal tracker
Edit `data/deals.json` only; see `DEALS_UPDATE.md`. The weekly scheduled task does this for you every Monday morning. The "Latest news" boxes refresh automatically with each workflow run.

## Notes and limits
- **Schedule and daylight saving:** GitHub cron runs in UTC, so the workflow is scheduled for both the EDT and EST times and a gate step lets through only the one that lands at 8 AM / 4 PM Eastern. GitHub can start scheduled runs several minutes late at busy times.
- **Quotes** use Yahoo Finance's unofficial public endpoint (no key). It is free and works well but is unofficial and can occasionally fail or be delayed; the page then shows the last good value marked stale. Futures and indices may be delayed.
- **Daily % change** is the latest price vs. the prior close.
- **FRED "released" dates** are the first-publication date of the latest figure. Daily and weekly series show the observation date instead.
- **WSJ headlines:** only titles and links are stored. If the WSJ feed ever fails, the script falls back to MarketWatch's feed (also Dow Jones) and the page says so.
- GitHub pauses scheduled workflows in repos with no activity for 60 days. The weekly deal-update commits should keep it active, but if GitHub ever disables the schedule, re-enable it from the Actions tab.
- This is for personal information, not investment advice.
